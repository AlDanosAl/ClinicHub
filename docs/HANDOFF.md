**Сделано:**
- Новый проект `ClinicHub.Web` (Blazor Web App, .NET 10, static SSR, без JavaScript), добавлен в `ClinicHub.slnx`.
- Главная по макету (артефакт «Сайт клиники Регеника», артборд «Главная»): hero, быстрая запись, услуги и цены, врачи, до/после, отзывы, каналы, статьи, подвал.

- Контент вынесен в `site-content.json` с заглушками в `[скобках]`.
- SEO: title/description/canonical/Open Graph, JSON-LD `MedicalClinic`, `robots.txt`, `sitemap.xml`.
- Заглушки страниц `/politika` и `/pravila`, русские 404 и страница ошибки.
- `ClinicHub.Core/PhoneNumbers.cs`: нормализация российских мобильных в E.164 (пригодится импорту 1.3).

**Следующие шаги:** AlDanosAl подтверждает ADR-0003 (Blazor) в ревью PR. Дальше страницы услуг и врачей, затем связка с Api (решить: in-process или HTTP, см. ADR-0003 «Последствия»).

## 2026-10-16 — Свят (сессия Claude) — документация, без ветки кода

**Сделано:**
- Разобран текущий код ClinicHub (коммит `6156f16`). Состав: Api (ASP.NET Core, EF/LocalDB, JWT, планировщик с лимитами SIM, авто-правило «день рождения», вебхук для сайта, LAN-discovery), Admin (MAUI), SmsAgent (Android, фоновый сервис, QR-подключение), Core.
- Подготовлен пакет документов: `CLAUDE.md`, `docs/ARCHITECTURE.md`, `docs/PLAN.md`, `docs/MIS-RESEARCH.md`, ADR 0001–0006, схема `docs/diagrams/system.md`.
- Черновик макета сайта (артефакт Design в claude.ai у Свята).

**Следующие шаги:** этап 0 из `PLAN.md`: GitHub-организация, перенос репо, доступы обоих аккаунтов, юр. часть (согласия), инвентаризация SIM и интернета.

**Известные проблемы в текущем коде (на этап 1):**
- `appsettings.json`: JWT-секрет лежит в репо. Сид-админ `admin / Admin123!`: сменить при первом запуске или генерировать.
- CORS `AllowAnyOrigin`: для веб-админки и сайта нужен явный список origin.
- `GET /api/webhook/requests/{id}/status` анонимный, по перебору id видны счётчики рассылок. Закрыть ключом, как POST.
- LocalDB не работает как служба (ADR-0006).
- Агент общается с сервером по HTTP без TLS. В LAN терпимо, но токен агента передаётся открыто.
- В README зашиты пути `C:\Users\xcx7276\…`: заменить на относительные.

**Решения:** ADR-0001 (хостинг в клинике), ADR-0002 (мастер-данные), ADR-0004 (Dikidi) приняты. ADR-0003, 0005, 0006 предложены и ждут AlDanosAl.
