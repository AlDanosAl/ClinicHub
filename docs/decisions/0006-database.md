# ADR-0006. PostgreSQL вместо SQL Server LocalDB

- Статус: **предложено** (2026-10-16)

## Контекст
Сейчас используется `(localdb)\MSSQLLocalDB`. LocalDB — компонент для разработки: она запускается в профиле пользователя, а не как служба, и для сервера, который должен работать без вошедшего пользователя, не подходит.

## Варианты
- **SQL Server Express**: минимальные изменения в коде. Ограничение 10 ГБ на базу (нам надолго хватит), работает только под Windows.
- **PostgreSQL**: бесплатный, без ограничений, кроссплатформенный (сервер можно ставить и на Linux), Свят с ним работает. EF Core подключается через Npgsql.

## Решение (предложено)
PostgreSQL. Миграции пересоздаём одной новой `InitialCreate`, потому что боевых данных ещё нет. Делаем это **до** импорта таблицы, пока переход стоит дёшево.
