# ADR-0003. Сайт на Blazor Web App (.NET) в том же решении

- Статус: **предложено** (2026-10-16), ждёт подтверждения обоих разработчиков

## Варианты
| Вариант | + | − |
|---|---|---|
| **Blazor Web App (static SSR + interactive server)** | один язык C# у обоих разработчиков; общий `ClinicHub.Core`; один процесс и деплой; SSR даёт нормальное SEO | меньше готовых UI-компонентов, чем в React-экосистеме |
| Next.js/React + отдельный API | богатая экосистема, лучшие шаблоны продающих сайтов | второй язык и рантайм (Node), два деплоя, дублирование DTO |
| Конструктор (Tilda и т.п.) + наш API | быстро сделать красиво | кабинет и админку всё равно писать самим; данные о заявках уходят в чужое облако |

## Решение (предложено)
Blazor Web App. Публичные страницы делаем на static SSR (быстро, индексируется), кабинет и админку — на interactive server. Стили: свой лёгкий CSS на токенах дизайн-системы из макета, без тяжёлых UI-китов.

## Последствия
- `ClinicHub.Web` ссылается на сервисы API напрямую (in-process) или через HTTP. Решим при старте этапа 4.
- MAUI-админка постепенно заменяется веб-админкой (ADR-0005).
