# ADR-0005. Веб-админка вместо MAUI-админки (постепенно)

- Статус: **предложено** (2026-10-16), ждёт согласия AlDanosAl, автора MAUI-админки

## Контекст
Сайту в любом случае нужна админ-панель: контент, кабинет, каналы. Если параллельно держать MAUI-админку под Windows, каждую функцию придётся делать дважды.

## Решение (предложено)
- MAUI-админка остаётся рабочей, пока веб-админка не повторит её функции: заявки, пациенты, телефоны, авто-правила.
- Новые функции делаем **только в веб-админке**.
- Когда достигнут паритет, MAUI-админка архивируется.
- Подключение телефона по QR (сейчас реализовано в MAUI) переносим в веб-админку первым, потому что его используют чаще всего.
