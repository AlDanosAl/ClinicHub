САЙТ КЛИНИКИ (ClinicHub.Web) — УСТАНОВКА НА КОМПЬЮТЕР КЛИНИКИ
=============================================================

Установка
---------
1. Распакуйте архив целиком в любую папку (например, на рабочий стол).
2. Дважды щёлкните install.cmd и разрешите запуск от имени администратора.
3. В конце окно покажет адреса сайта:
     - на этом компьютере:   http://localhost:8080/
     - с других компьютеров и телефонов в той же сети:  http://<IP этого компьютера>:8080/
   На рабочем столе появится ярлык «Сайт клиники».

Сайт запускается сам при включении компьютера, входить в Windows не нужно.
Если сайт упадёт, Windows перезапустит его через минуту.

Если порт 8080 занят другой программой, установите на другой порт:
откройте командную строку в этой папке и выполните   install.cmd 8081

Переносимая сборка требует ASP.NET Core Runtime 10. Установщик проверит его сам и, если нужно,
поставит через winget (нужен интернет). Если не получится, он откроет страницу загрузки.

Изменить тексты, телефон, адрес, услуги и врачей
-------------------------------------------------
Файл C:\ClinicHub\Web\site-content.json — откройте Блокнотом, поправьте, сохраните.
Сайт подхватит изменения сам, перезапускать ничего не нужно.
Значения в [КВАДРАТНЫХ СКОБКАХ] — заглушки, их нужно заменить на настоящие данные.
При переустановке новой версии этот файл НЕ перезаписывается.

Обновление
----------
Распакуйте новую версию и снова запустите install.cmd. Ваш site-content.json останется прежним.

Удаление
--------
Дважды щёлкните uninstall.cmd. Копия site-content.json сохранится на рабочий стол.

Важно
-----
- Это демонстрационная версия: онлайн-запись показывает примерное расписание и никуда не отправляет заявки
  (на странице записи висит жёлтое предупреждение).
- Сайт работает только внутри сети клиники по HTTP. Выкладывать его в интернет в таком виде нельзя:
  нужны домен, HTTPS и тексты политики персональных данных (PLAN, задачи 0.5 и 4.4).
